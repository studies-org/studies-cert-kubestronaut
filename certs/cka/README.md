# CKA — Certified Kubernetes Administrator

```
   ┌──────────────────────────────────────────┐
   │  ⚙️   ETAPA 4/5  —  OPERAR O CLUSTER     │
   └──────────────────────────────────────────┘
```

Certificação **prática** (hands-on) que valida a habilidade de instalar,
configurar e operar clusters Kubernetes em produção.

## Formato da prova

| Item             | Detalhe                                  |
|------------------|------------------------------------------|
| Tipo             | Performance-based (terminal real)        |
| Duração          | 2 horas                                  |
| Nota mínima      | 66%                                      |
| Validade         | 2 anos                                   |
| Pré-requisitos   | Nenhum                                   |

## Domínios (peso aproximado)

- **Storage** — 10%
- **Troubleshooting** — 30%
- **Workloads & Scheduling** — 15%
- **Cluster Architecture, Installation & Configuration** — 25%
- **Services & Networking** — 20%

## Recursos de estudo

- **Descomplicando Kubernetes (LinuxTips / Jeferson)** ⭐⭐ (prioridade máxima — curso é forte em CKA)
- **KodeKloud — CKA course + labs** ⭐
- **killer.sh** — simulador oficial (2 sessões grátis com o voucher)
- [Currículo oficial CNCF](https://github.com/cncf/curriculum)
- [kubernetes/website docs](https://kubernetes.io/docs/) (permitido na prova)

## Tópicos críticos

- `kubeadm` — bootstrap, upgrade, join/reset
- ETCD — backup e restore
- Troubleshooting de kubelet, control plane, DNS, CNI
- RBAC, Service Accounts
- Network Policies

## Dicas

- Decorar bookmarks da doc oficial (única referência permitida).
- Treinar `vim` ou `nano` — não dá pra alternar com mouse de boa.
- Saber sair de qualquer cilada com `kubectl describe` e `journalctl`.
