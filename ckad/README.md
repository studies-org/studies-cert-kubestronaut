# CKAD — Certified Kubernetes Application Developer

```
   ┌──────────────────────────────────────────┐
   │  🧑‍💻  ETAPA 3/5  —  DEV NO CLUSTER       │
   └──────────────────────────────────────────┘
```

Certificação **prática** (hands-on) que valida a habilidade de projetar,
construir e implantar aplicações cloud native em Kubernetes.

## Formato da prova

| Item             | Detalhe                                  |
|------------------|------------------------------------------|
| Tipo             | Performance-based (terminal real)        |
| Duração          | 2 horas                                  |
| Nota mínima      | 66%                                      |
| Validade         | 2 anos                                   |
| Pré-requisitos   | Nenhum                                   |

## Domínios (peso aproximado)

- **Application Design and Build** — 20%
- **Application Deployment** — 20%
- **Application Observability and Maintenance** — 15%
- **Application Environment, Configuration and Security** — 25%
- **Services and Networking** — 20%

## Recursos de estudo

- **KodeKloud — CKAD course + labs** ⭐ (prioridade)
- **killer.sh** — simulador oficial (2 sessões grátis com o voucher)
- [Currículo oficial CNCF](https://github.com/cncf/curriculum)
- [dgkanatsios/CKAD-exercises](https://github.com/dgkanatsios/CKAD-exercises)

## Dicas

- Treinar `kubectl` ao ponto de digitar de olhos fechados.
- Dominar `--dry-run=client -o yaml` para gerar manifestos rapidamente.
- Configurar aliases (`alias k=kubectl`) e autocomplete antes da prova.
- Praticar com cronômetro — tempo é o maior inimigo.
